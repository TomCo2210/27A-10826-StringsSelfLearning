# לומדת מחרוזות ב-C — 10826

לומדה ללימוד עצמי של פרק המחרוזות (הנושא שמוגדר בסילבוס כלימוד עצמי שנכלל בבחינה הסופית).
15 יחידות בחמישה חלקים, עם סימולציות של הזיכרון, שאלות בסוף כל יחידה, "מצאו את הבאג", חידון מסכם ותרגילי כתיבה.

## הרצה

- **GitHub Pages:** כל דחיפה ל-`main` מפרסמת את הלומדה ב-https://tomco2210.github.io/27A-10826-StringsSelfLearning/
- **מקומית:** לפתוח את `index.html` בדפדפן (לחיצה כפולה). לא צריך שרת.
- **במודל:** לדחוס את התיקייה ל-zip, להעלות כמשאב "קובץ" (או "תיקייה"), לפתוח את הקובץ ב-Moodle ולבחור "Unzip", ולהגדיר את `index.html` כקובץ הראשי. הקישורים היחסיים לקבצי `css/` ו-`js/` עובדים כך כמו שהם.
- הגופנים נטענים מ-Google Fonts. בלי אינטרנט הלומדה עובדת עם גופני מערכת.

## אילו פרקים לכלול (Secrets)

ארבעה פרקים אפשר להוציא מהלומדה. פרק שהוצא נעלם לגמרי: מהתפריט, מתוכן העניינים, מההפניות ביחידות אחרות, ומהשאלות בחידון ובתרגול שעוסקות בו. המספור של שאר היחידות מתעדכן לבד.

| Secret | במה הוא שולט | ברירת מחדל |
|---|---|---|
| `INCLUDE_STRTOK` | יחידה "פירוק עם strtok", ו-2 שאלות בחידון המסכם | `true` |
| `INCLUDE_CTYPE` | יחידה "הספרייה ctype.h", 2 קטעים ב"מצאו את הבאג", שאלה בחידון, ותרגיל `capitalizeWords` | `true` |
| `INCLUDE_SPRINTF_SSCANF` | יחידה "sprintf ו-sscanf", שאלה בחידון, וקטע ההעמקה על `sprintf` ביחידת הקלט | `true` |
| `INCLUDE_PRACTICE` | חלק ה' כולו: מצאו את הבאג, חידון מסכם, תרגילי כתיבה. השאלות שבסוף כל יחידה נשארות | `true` |

**שינוי ערך ב-GitHub:**
1. בריפו: Settings → Secrets and variables → Actions.
2. בלשונית Secrets, ליד ה-Secret: עריכה (העיפרון), ולכתוב `true` או `false`.
3. שינוי של Secret לא מפעיל פריסה מחדש לבד: Actions → Deploy to GitHub Pages → Run workflow.
4. אחרי דקה-שתיים האתר מתעדכן. בסיכום של הריצה (Summary) יש טבלה של הערכים שהופעלו.

ערך ריק או Secret שנמחק = ברירת המחדל שב-`js/config.js`. ערך אחר מ-true/false מכשיל את הריצה עם הודעת שגיאה, והאתר הקודם נשאר באוויר.
אפשר להגדיר אותם גם כ-Variables (באותו מסך, לשונית Variables), ואז רואים את הערך הנוכחי בלי לפתוח עריכה. אם יש גם Secret וגם Variable באותו שם, ה-Secret קובע.

**בהעלאה ידנית (zip למודל)** אין Secrets: משנים את הבלוק `include` ב-`js/config.js` לפני הדחיסה.

## הגדרות (`js/config.js`)

- `include` — אילו פרקים לכלול (ראו למעלה).
- `showSolutions` — `false` מסתיר את הפתרונות המלאים ביחידה 15 ומשאיר רמזים בלבד. שימושי עד מועד ההגשה של תרגיל 3.
- `parts` — סדר החלקים והיחידות. להזיז יחידה = להזיז את ה-id שלה ברשימה.
- `storageKey` — שינוי הערך מאפס את ההתקדמות השמורה של כל הסטודנטים (למשל בתחילת סמסטר).

## הוספת יחידה

1. ליצור `js/units/16-<name>.js` לפי התבנית:

```js
(function () {
  'use strict';
  const L = window.Lomda;
  L.unit({
    id: 'my-unit',                     // ASCII, מופיע בכתובת: index.html#my-unit
    title: 'כותרת היחידה',
    blurb: 'שורה אחת לתוכן העניינים',
    minutes: 10,
    lede: 'פסקת פתיחה',
    goals: ['מטרה 1', 'מטרה 2'],
    build(host) {
      host.innerHTML = '<p>…</p>' + L.code(['int x = 0;']) + L.note('key', 'כותרת', 'טקסט');
      // רכיבים אינטראקטיביים: L.mem, L.player, L.tabs, L.quiz
    },
    check: [ { q: 'שאלה', opts: ['א', 'ב'], a: 0, why: 'הסבר' } ]   // לא חובה
  });
})();
```

2. להוסיף `<script src="js/units/16-<name>.js"></script>` ב-`index.html`, לפני `app.js`.
3. להוסיף את ה-id לחלק המתאים ב-`config.js`.

## התקדמות הסטודנטים

נשמרת ב-`localStorage` של הדפדפן בלבד: אילו יחידות סומנו כהושלמו, ותשובות לשאלות. שום מידע לא נשלח לשום מקום, וההתקדמות לא עוברת בין מחשבים. בחלון פרטי הלומדה עובדת בלי שמירה. יש כפתור איפוס בתחתית דף הבית.

## מה נבדק

- **קוד C:** הפתרונות של יחידה 15 עוברים `gcc -std=c99 -Wall -Wextra -pedantic` בלי אזהרות, ועוברים 21 בדיקות כולל מקרי קצה (מחרוזת ריקה, רווחים בלבד, רווחים כפולים). קטעי הקוד מהיחידות (toUpperStr, makeInitials, מיון שמות, strtok, sscanf, פורמטים של printf) הורצו, והפלטים שמוצגים בלומדה תואמים לפלט האמיתי.
- **הלומדה:** כל אחת מ-15 היחידות נטענה ב-Chromium, בכל לשונית הנגנים הורצו עד הסוף, השאלות נענו והשדות שונו. אין שגיאות JavaScript, ואין גלילה אופקית ברוחב 1280 וברוחב טלפון (390).
